Mariya Birthday Site — how to open

Option A — open the built site (no install needed if you have npx):
  cd ~/Documents/mariya-birthday-site
  npx serve dist

Option B — run the Vite/React app in development:
  cd ~/Documents/mariya-birthday-site
  npm install
  npm run dev

Then open the URL printed in the terminal (usually http://localhost:5173 for Option B, or the port serve prints for Option A).
