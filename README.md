# For Mariya · 21

A magical multi-chapter birthday journey for Mariya — from Yaseen.

## Chapters

1. **The Door** — mysterious portal opening
2. **Yellow** — sunflower hero (“my yellow person”)
3. **Surprise** — sealed envelope letter
4. **Memories** — interactive photo gallery
5. **Letters** — love messages
6. **Secrets** — hidden clues & discoveries
7. **21** — birthday finale

## Preview

```bash
npm install
npm run dev
```

Open the printed local URL (usually `http://localhost:5173`).

## Production build

```bash
npm run build
npm run preview
```

Static output lands in `dist/`.
